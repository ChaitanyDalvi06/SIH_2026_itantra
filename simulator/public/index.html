Cryptographic Security Specification

  • Monotonic Sequence Window: Sliding window (128 packets) rejects expired or out-of-order replayed frames.
  • Message ID Deduplication: Unique 64-bit ID prevents duplicate speech playback during lost ACKs.
  • HMAC-SHA256 / AES-GCM Integrity: 16-byte authentication tag guarantees tamper-proof payloads.
  • Memory Bounds: Bounded 4,096-byte max payload prevents memory exhaustion & DoS.
  • Zero Audio Storage: Raw microphone PCM lives only in transient RAM, discarded immediately after inference.
